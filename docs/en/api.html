calls

Originate several parties into a shared ConfBridge conference room

Authorizations:
tokenAuth
Request Body schema:
required
callerid
string <= 128 characters

Caller ID applied to the call, format 'name', e.g. '380443333333<0675653380>'.

timeout_ms
integer [ 1000 .. 120000 ]
Default: 30000

Max time to wait for the call to answer, in milliseconds.

parties
required
Array of strings >= 2 items [ items <= 256 characters ]

Channels to originate into the same conference room, e.g. ["PJSIP/101", "PJSIP/0504139380@mega-provider", "Local/2222@internal"].

room
string <= 64 characters

Conference room number. If omitted, a new one is generated and returned in the response.

context
string <= 128 characters

Dialplan context that lands each leg into ConfBridge. Defaults to settings.PEARLPBX_CONFERENCE_CONTEXT.

Responses

/api/v1/calls/conference/

Request samples

  • Payload
Content type
{
  • "callerid": "string",
  • "timeout_ms": 30000,
  • "parties": [
    • "string",
    • "string"
    ],
  • "room": "string",
  • "context": "string"
}

Originate a call

Authorizations:
tokenAuth
Request Body schema:
required
callerid
string <= 128 characters

Caller ID applied to the call, format 'name', e.g. '380443333333<0675653380>'.

timeout_ms
integer [ 1000 .. 120000 ]
Default: 30000

Max time to wait for the call to answer, in milliseconds.

channel
required
string <= 256 characters

First leg to dial, e.g. 'Local/0503856087@default' or 'PJSIP/101'.

exten
required
string <= 128 characters

Extension/number the first leg is connected to, e.g. '0675653380'.

context
string <= 128 characters
Default: "default"

Dialplan context. Defaults to 'default'.

priority
integer >= 1
Default: 1

Dialplan priority.

object

Channel variables, e.g. {"userId": "0"}.

Responses

/api/v1/calls/originate/

Request samples

  • Payload
Content type
{
  • "callerid": "string",
  • "timeout_ms": 30000,
  • "channel": "string",
  • "exten": "string",
  • "context": "default",
  • "priority": 1,
  • "variable": {
    • "property1": "string",
    • "property2": "string"
    }
}
